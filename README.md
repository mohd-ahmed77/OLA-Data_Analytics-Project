## 📌 **Overview**

An end-to-end data analytics project analyzing **July 2024 ride-sharing data (~100K records)** to extract actionable business insights. This project demonstrates skills in data cleaning, querying, and visualization using **Microsoft Excel**, **SQL**, and **Microsoft Power BI**.

## 📊 **Dataset Details**

* 📁 **Records:** ~100,000 rows
* 📌 **Columns:** 19
* 📅 **Time Period:** July 2024
* 📍 **Key Features:**

  * Booking Status
  * Vehicle Type
  * Ride Distance
  * Payment Method
  * Customer & Driver Ratings

---

## 🧑‍💻 **Project Workflow**

### 1️⃣ Data Cleaning (**Excel**)

* Removed duplicates & handled missing values
* Standardized formats for consistency

### 2️⃣ Data Analysis (**SQL**)

* Analyzed booking trends and revenue
* Identified cancellation patterns
* Compared customer vs driver ratings
* Extracted top customers & vehicle insights

### 3️⃣ Dashboard Development (**Power BI**)

* Built **6 interactive dashboards**
* Designed business-focused visualizations

---

## 📈 **Key Insights**

* 📌 Peak demand during **evenings & weekends**
* 📌 **Driver cancellations > Customer cancellations**
* 📌 **Digital payments dominate revenue**
* 📌 Premium vehicles → higher ratings
* 📌 Strong correlation between customer & driver ratings

---

## 🎯 **Business Impact**

* Improved understanding of ride demand patterns
